# Francesca Pia Panaccione — Academic website (v12)

This is a lightweight, static HTML/CSS/JavaScript site for GitHub Pages. **No Astro, Node.js, or build action is required.**

## Preview
Open `index.html` in a browser.

## Deploy to GitHub Pages (first time)
1. Sign in to GitHub as **francescapia**.
2. Visit https://github.com/new and create a **public** repository called **francescapia.github.io**.
3. Add all files from this directory at the repository root. Important: upload **index.html**, **.nojekyll**, and the **assets/** directory, not a parent folder containing them.
4. Commit to `main`.
5. Open repository **Settings > Pages**. Under **Build and deployment**, select **Deploy from a branch**, **main**, **/(root)**, and save.
6. Your website will appear at https://francescapia.github.io/. GitHub may take several minutes to publish.

## Updating
Edit `index.html`, commit/push to `main`. The public website updates automatically.
